# AGENTS.md — orientation for AI agents working in this repository

Read this file first. It is deliberately short. It tells you what this repository
is, where the durable context lives, and which rules are not negotiable.

## What this is

`glampro_new` is a **complete rebuild** of the Glampro / Salon Pro salon
management SaaS (glamproplus.com) as a Docker-first TypeScript monorepo:

| Workspace         | Stack                                                            |
| ----------------- | ---------------------------------------------------------------- |
| `apps/web`        | React 19 · TypeScript · Vite 8 · Tailwind 4 · TanStack Query 5   |
| `apps/api`        | Express 5 · TypeScript · Prisma 7 · Zod · PostgreSQL 17          |
| `packages/shared` | Zod schemas and API contracts shared by both                     |
| `design/handoff/` | The vendored Salon Pro redesign handoff (screens, tokens, icons) |

The legacy application is a **separate Laravel/MySQL/React codebase living outside
this repository** (path in `docs/legacy/LEGACY-MAP.md`). It is reference material
only. Nothing is copied from it blindly; everything is deliberately re-modelled.

## Non-negotiable rules

1. **Tenant isolation is enforced in code, never trusted from the request.**
   `tenantId` comes from the verified JWT only. Every tenant-scoped query is
   scoped by a Prisma client extension. Never read a tenant id from a body, query
   string or header. See [`docs/saas/TENANCY.md`](docs/saas/TENANCY.md).

2. **Design tokens are copied, not invented.** `apps/web/src/styles/tokens.css` is
   a verbatim copy of `design/handoff/tokens/tokens.css`. Never edit token values
   in place; change the handoff file and re-copy, then map through `@theme`.

3. **`/api/mobile/*` is a frozen contract.** The existing mobile client depends on
   its exact paths, field names and response shapes. Do not "improve" it.

4. **Never edit `apps/api/generated/`.** It is regenerated by `npm run db:generate`.

5. **Migrations are committed SQL, always.** `prisma migrate dev` locally,
   `prisma migrate deploy` everywhere else. Never `db push` outside a spike.

6. **Shared contracts live in `packages/shared`.** If a shape crosses the
   network, its Zod schema belongs there so the API and the browser cannot drift.

7. **`npm run verify` must pass before a phase is called done** (format check,
   lint, type-check, all tests). Keep the tree green at every phase boundary.

8. **Secrets never enter the repository, an image, or a `VITE_*` variable.**
   `VITE_*` values ship to the browser.

## Working style in this repository

- TypeScript is strict with `erasableSyntaxOnly`: **no enums, no runtime
  namespaces, no parameter properties.** Use `const` objects plus a derived union
  type, or a Zod enum.
- Commit **one phase per commit** with a message naming the phase.
- Prefer small, verifiable changes. If a change cannot be verified by a test or a
  running stack, say so explicitly rather than asserting it works.
- When information is missing, search the legacy codebase and record the answer in
  the relevant `docs/` file — do not guess and do not leave it in the transcript.
